Initiative, not a model

Local intelligence. Defensive engineering. Control by design.

CALYX is an engineering initiative by Oblivion. It asks how AI can support defensive security work, and how people can have a better experience running language models on their own machines.

It is not a foundation model, and it does not perform autonomous cyber defense. This page separates what exists, what is experimental, and what remains a design goal.

Local models offer private, controllable workflows. Working with several of them creates orchestration problems. And a capable model is not enough for security work: it needs boundaries, verification, and behavior a person can understand.

The three products, Angra, Nythos and Nythos Plus, each address one of those problems.

Angra

Connects and coordinates local models.

Nythos

Gives a local assistant inspectable, user-controlled memory.

Nythos Plus

Extends the family toward adaptive effort.

Security is an engineering discipline.

Running a model locally can give people more control over where their data goes. It does not make a system secure or private by itself. That depends on the implementation, operating environment, configuration, dependencies and ongoing maintenance.

The principles below are engineering goals, informed by OWASP ASVS and NIST SSDF as references. They are not certifications, and CALYX has not been externally audited.

Verification status

No external audit published. No penetration test published. Release signing not published. Treat every claim on this page as design intent unless it links to evidence.

Administrative control center.

This site is static and hosted on GitHub Pages. A static page cannot hold secrets, authenticate administrators or enforce permissions, so there is deliberately no working login here.

Planned scope: public project descriptions, release notes, documentation links, an audit trail of authorized changes, and service health when real monitoring data exists. Each of these needs a trusted server with server-side authentication and authorization.

API boundary

Set CALYX_API_BASE in the script to a real HTTPS endpoint. It is empty by default, so privileged actions stay disabled.
